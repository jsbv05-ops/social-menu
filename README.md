# Social Drinks & Coffee — Carta digital

Sitio estático (un solo `index.html` + `logo.png`). No necesita build.

- Para cambiar precios o productos: edita los bloques `COCTELES` y `CARTA` al inicio del `<script>` en `index.html`.
- Despliegue en Vercel: importar el repositorio, framework "Other", sin comando de build, directorio de salida `.`.
